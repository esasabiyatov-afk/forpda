## ForPDA Mod — сборка для sideload

Неофициальная модификация [ForPDA](https://github.com/SubvertDev/ForPDA) 0.13.0 — последний стабильный релиз автора (с разрешения автора). Неподписанный `.ipa`: подпись делает программа установки.

### Какой файл выбрать
| Файл | Для чего |
|---|---|
| `…-sideload.ipa` | **SideStore / AltStore / Sideloadly / iloader с бесплатным Apple ID.** Без расширений — занимает 1 App ID. |
| `…-full.ipa` | **TrollStore, Feather / ESign / Scarlet, платный сертификат.** С расширением Safari и расширением уведомлений. |

Если не уверены — берите `sideload`.

### Установка
- **SideStore / AltStore:** My Apps → «+» → выберите `.ipa`. Подпись продлевается раз в 7 дней.
- **Sideloadly:** перетащите `.ipa`, войдите своим Apple ID.
- **iloader** (Windows / macOS / Linux): подключите iPhone, войдите своим Apple ID, выберите `.ipa` для установки.
- **TrollStore:** откройте `.ipa` через «Поделиться» → TrollStore.

### Отличия от оригинала
- Своё название **ForPDA Mod** и фиолетовая иконка с плашкой MOD — не путается с официальной версией на главном экране.
- В настройках версия отображается с каналом `[Mod]`.

### Исправления
- Вылет при запуске после установки через sideload (отсутствующая App Group).
- Вылеты при изменении формата ответов 4pda: темы, профиль, QMS, статьи, избранное, DevDB.
- Вылеты при отображении постов: пустой `[img]`, нестандартный `[list]`, битые вложения, непарные теги.
- Вылеты на ссылках с пробелами/кириллицей, на вложениях QMS с эмодзи в имени, при загрузке файлов.
- Аналитика Sentry/PostHog отключена — данные не отправляются.

### Ограничения
- Push-уведомления не работают ни в одной версии: они идут через сервер и ключи Apple автора оригинала.

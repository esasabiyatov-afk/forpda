## ForPDA Mod — сборка для SideStore

Неподписанный `.ipa` для установки через SideStore / AltStore / Sideloadly (подпись делает сам SideStore вашим Apple ID). Основано на ForPDA 0.14.0.

### Установка
1. Скачайте `.ipa` ниже (в разделе Assets).
2. SideStore → My Apps → «+» → выберите файл.

### Исправления
- Вылет при запуске после установки через SideStore (отсутствующая App Group).
- Вылеты при изменении формата ответов 4pda: темы, профиль, QMS, статьи, избранное, DevDB.
- Вылеты при отображении постов: пустой `[img]`, нестандартный `[list]`, битые вложения, непарные теги.
- Вылеты на ссылках с пробелами/кириллицей, на вложениях QMS с эмодзи в имени, при загрузке файлов.
- Аналитика Sentry/PostHog отключена (нет ключей) — данные не отправляются.

### Ограничения
- Без расширений Safari и уведомлений (экономия App ID на бесплатном аккаунте), push-уведомлений нет.
